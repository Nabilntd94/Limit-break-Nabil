# LIMIT BREAK 4.1 — Power-Up Edition

**ZIP completo:** incluye todo lo necesario para publicar LIMIT BREAK 4.1 en GitHub Pages.

## Qué cambia
- Tres portadas anime/gimnasio en Hoy, Entrenos y Progreso.
- 16 fotografías de referencia de ejercicios generadas específicamente para la app (no fotos de Fitness Park).
- En las fichas de 63 ejercicios se usa una fotografía adecuada al movimiento cuando hay una referencia visual orientativa; en el resto se muestra claramente que la imagen específica está pendiente. Nunca se usa un monigote de la versión anterior.
- Misma planificación semanal, edición de ejercicios, nutrición y progreso que la 4.0.
- Conserva los registros locales de la versión 4.0 **si se publica en la misma dirección y se utiliza el mismo navegador**.

## Publicación sin borrar la configuración
1. No elimines el repositorio ni `.github/workflows/static.yml` (si esa configuración existe y publica correctamente).
2. Extrae el ZIP, selecciona **el contenido**, no la carpeta padre.
3. Súbelo a la raíz del repositorio desde GitHub > Code > Add file > Upload files.
4. Verifica el despliegue en Actions.
5. No subas JSON de datos privados al repositorio.

**Nota:** las imágenes de referencia de ejercicios se han generado con IA y pueden tener imperfecciones biomecánicas. Si necesitas aprender un ejercicio nuevo, solicita una demostración a un profesional. Las máquinas disponibles cambian según el club.
