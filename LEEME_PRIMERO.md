## Instalacion
1. No borres la carpeta `.github/workflows` de tu repositorio.
2. Sube TODO el contenido de esta carpeta a la raiz del repositorio de GitHub.
3. Comprueba que `index.html`, `app.js`, `catalog46.js`, `upgrade45.js` y los demas archivos se actualicen en main.
4. Espera al despliegue verde de GitHub Actions.
5. Si el iPhone sigue mostrando una version anterior, cierra la app y prueba la URL en Safari.

El almacenamiento local y la clave de datos no cambian. No elimines la app instalada ni borres los datos de Safari.
